The `sam2/` subdirectory should contain the following files:

- [sam2_hiera_base_plus.pt](https://huggingface.co/facebook/sam2-hiera-base-plus/resolve/main/sam2_hiera_base_plus.pt)
- [sam2_hiera_large.pt](https://huggingface.co/facebook/sam2-hiera-large/resolve/main/sam2_hiera_large.pt)
- [sam2_hiera_small.pt](https://huggingface.co/facebook/sam2-hiera-small/resolve/main/sam2_hiera_small.pt)
- [sam2_hiera_tiny.pt](https://huggingface.co/facebook/sam2-hiera-tiny/resolve/main/sam2_hiera_tiny.pt)

Download them manually or using the *ComfyUI Manager* into `$COMFYUI_DIR/models/sam2/*.pt`.

They were originally part of this repo, but LFS quotas are scarce on GitHub. Thanks to TemperedTyrant for reporting this issue.
